Handwritten notes and PDF annotation for Android tablets, saved as plain Excalidraw files.

Download for Android Obsidian plugin
Android 10 or newer. Made on a Galaxy Tab S9.
Signals and Systems, lecture 3

Ink that keeps up

Strokes appear right under the pen tip and look the same after you lift it, and the same again in Excalidraw.

Write on your PDFs

Import slides or papers, even hundreds of pages long. Add blank pages anywhere in between for working.

Real pages

A4 in portrait or landscape. Swipe past the last page to add another. Fit the page or the width, edge to edge.

The pen draws, fingers move

Fingers scroll and zoom while the pen draws, so your hand can rest on the screen. Hold the S Pen button to erase, or hold it still to select and paste.

Pens that feel different

Pen, fineliner, pencil, chalk and highlighter, with fine sizes and your last colors one tap away.

Your folders, your files

Keep notes in any folder, like an Obsidian vault, and sync them however you want. Paste images straight in.

Watch it live

Turn on Live on the tablet and anyone with the five-letter code can follow along in a browser: on a projector, on a classmate's laptop, on your phone.

They see each stroke as you draw it and follow you through the pages. They can look, not edit, and nothing is stored online.

Five letters, shown under Live in the app.

Just a file

Every note is an ordinary .excalidraw file. No account, no cloud, nothing to export.

  • Open it at excalidraw.com, strokes and all
  • Keep it in your Obsidian vault: the Obsidian plugin shows notes with their PDF pages, and tapping one opens it in the app
  • Version it with git, diff it, script it
  • Open any .excalidraw file from a file manager and edit it in place
// Lecture 3.excalidraw
{
  "type": "excalidraw",
  "elements": [
    { "type": "frame",
      "name": "Page 4",
      "customData": { "background": {

        "file": "Lecture 3.pdf",
        "page": 3 } } },
    { "type": "freedraw",
      "strokeColor": "#e03131",
      "points": [[0, 0], [4.2, 1.9], …],
      "pressures": [0.31, 0.44, …] }
  ],
  "inkcalidraw": { "pens": { … } }
}
